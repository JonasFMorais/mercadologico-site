# Site institucional MercadoLógico

Esta pasta contém a versão estática publicada do site institucional do MercadoLógico, separada do aplicativo móvel.

## Publicação

O workflow `.github/workflows/deploy-website-pages.yml` publica esta pasta no GitHub Pages sempre que houver alteração em `website/**` na branch `main`.

O domínio personalizado está declarado em `CNAME` como `mercadologico.app.br`.

## Origem

A versão foi exportada da publicação institucional do projeto Manus e mantida como uma superfície pública independente. Não contém segredos, credenciais ou dados pessoais do aplicativo.
